Privacy Policy

ListingView · Last updated July 2026

ListingView is a single-user application: it is operated by its developer to manage the developer's own Etsy shop. It has no user accounts, no sign-up, and no users other than the developer. This policy describes what data the application handles and how.

Data the application accesses

  • Etsy shop and listing data for the one shop that authorized it — shop profile, listings, listing photos, and digital files — retrieved and written via the official Etsy Open API v3 under OAuth scopes listings_r, listings_w, shops_r, shops_w.
  • OAuth tokens issued by Etsy when the shop owner authorizes the app.
  • Artwork and product files the shop owner uploads in order to create listings.

The application does not access buyer names, addresses, messages, payment details, or any personal data of Etsy buyers, and does not access any Etsy shop other than the one that authorized it.

Where data is stored

  • OAuth tokens are stored server-side in the developer's own Cloudflare Workers KV storage, accessible only to the developer's backend service.
  • Artwork, generated mockups, and app settings live in the shop owner's browser (memory and localStorage) on the shop owner's own device.
  • Listing content submitted for publishing is transmitted to Etsy via the Etsy API and stored by Etsy under Etsy's own privacy policy.

What is never done with data

  • No data is sold, rented, or shared with third parties.
  • No analytics, advertising, or tracking scripts are used.
  • No data about any person other than the developer is collected.

Data retention and deletion

OAuth tokens persist until the shop owner revokes the app's access (via Etsy's Apps with access settings) or deletes them from the backend, at which point the application can no longer access the shop. Locally stored settings can be cleared at any time by clearing the browser's site data.

Contact

Questions about this policy can be raised through the developer's GitHub profile, where the application's source code is published.
