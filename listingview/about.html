⌕ ListingViewEtsy listing management & publishing suite

A personal listing-management tool for one Etsy shop

ListingView is a single-user application built and operated by its developer to manage the developer's own Etsy shop. It is not offered as a service to other sellers, has no user accounts, and connects to exactly one Etsy shop: the developer's.

What the application does

  • Creates and manages listings for the connected shop: titles, descriptions, tags, prices, photos, and digital files.
  • Generates listing photos by rendering the shop's own artwork onto product mockups (mug, tee, tote, hoodie, sticker, poster) in the browser.
  • Writes listing SEO: titles, up to 13 tags within Etsy's 20-character limit, and long-form descriptions, scored against Etsy best practices before anything is posted.
  • Bulk edits the shop's existing listings — find & replace, price adjustments, photo slot changes — with a before/after preview prior to publishing.
  • Uploads digital files so buyers of the shop's digital products receive their downloads through Etsy's standard delivery.

How it uses the Etsy API

The app integrates with the official Etsy Open API v3 using OAuth 2.0 with PKCE. It requests the listings_r, listings_w, shops_r, and shops_w scopes, authorized once by the shop owner (the developer). It calls the API to:

  • read the connected shop's profile and listings,
  • create draft listings and upload their photos and digital files,
  • update or activate those listings when the owner chooses to.

Listings are created as drafts by default; nothing goes live without an explicit action by the shop owner. The app accesses no buyer personal data and no data from any shop other than the one that authorized it.

Who operates it

ListingView is developed and operated by an independent Etsy seller for their own shop. Questions can be directed through the developer's GitHub profile, where this application's source code is published.
